# 💸 얼마썼니 - 음성 가계부

설치 없이 브라우저에서 동작하는 가계부 앱입니다. (데이터는 브라우저 localStorage에 저장)

## 기능
- 📅 **달력**: 날짜별 수입/지출 합계, 날짜 선택 시 상세 내역
- 📋 **내역**: 월별 리스트, 검색, 수정/삭제
- 📊 **통계**: 카테고리별 지출, 월 예산 진행률, 최근 6개월 추이
- 💳 **카드혜택**: 카드 등록(신용/체크), 카테고리별 적립·할인율, 전월실적/월 한도,
  이번 달 예상 포인트, "이 카드로 결제했다면 N원 더 절약" 추천
- 🎤 **음성 가계부**: "쿠팡에서 오늘 삼성이로 삼만원짜리 충전기 샀어" → 금액/날짜/카드/카테고리 자동 분류
  - "월급 들어왔어" → 설정한 월급이 수입으로 입력
  - 인식 결과는 확인 창에서 수정 후 저장
- 백업(JSON), CSV 내보내기

## 귀여운 카드 등록 🐰
- 카드사 → 카드 종류를 고르면 혜택/전월실적/한도가 자동으로 채워집니다 (`cards-db.js`, 웹 검색으로 정리한 참고용 데이터)
- 목록에 없는 카드는 "웹에서 혜택 검색하기" 링크로 확인 후 직접 입력
- 별명 추천 칩(콩이, 몽실이…), 캐릭터 이모지, 카드 색상 선택

## 실행
Chrome에서 음성 인식을 쓰려면 로컬 서버(localhost) 또는 HTTPS가 필요합니다.
```
cd how_spend_money
python -m http.server 8080
# 브라우저에서 http://localhost:8080
```

## 사용 순서
1. ⚙️ 설정에서 월급/월 예산 입력
2. 💳 카드혜택에서 카드 등록 (별명 예: 삼성이, 롯데이 / 혜택 예: `기본:0.5, 식비:5, 교통:10`)
3. 🎤 버튼을 누르고 말하기
